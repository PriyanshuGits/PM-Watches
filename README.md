# PM Watches ⌚

**A premium smartwatch experience built with modern UI, interactive 3D visuals, and full-stack technology.**

PM Watches is a premium smartwatch e-commerce experience focused on creating a clean, immersive, and modern product journey.

The project combines **modern UI/UX, interactive 3D product visualization, authentication, database integration, and admin functionality** into one complete web experience.

## ✨ Highlights

- Premium and responsive user interface
- Interactive 3D smartwatch experience
- Modern product showcase
- Smooth animations and interactions
- User authentication and session persistence
- Sign up, login, logout, and forgot password flow
- Protected admin access
- Complete smartwatch product management
- Add, edit, delete, and manage watches
- MongoDB-powered product data
- Responsive experience across devices

## 🛠️ Built With

**Frontend:** React, Vite, CSS, Three.js, React Three Fiber, React Three Drei

**Backend:** Node.js, Express.js, MongoDB, Mongoose

**Authentication:** JWT, secure cookie-based sessions

**Tools:** Git, GitHub, MongoDB Compass
